# Changelog

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).
Версия задаётся в `.claude-plugin/plugin.json` (у плагина Claude нет `pyproject.toml`).

## [1.0.0] — 2026-10-07

### Добавлено
- Каждое сообщение пользователя становится главой во встроенном оглавлении Claude Desktop
  (вкладка Code), сразу под сообщением: название — начало сообщения до 39 символов,
  описание — до 200. Переход к сообщению — кликом по главе в оглавлении.
- Глава ставится первым шагом хода, который делает плагин без запроса к модели
  (хук `turn.step`): вызов `mcp__ccd_session__mark_chapter` попадает в переписку, по
  которой десктоп строит оглавление. Лишних запросов к модели нет.
- Запасной способ на случай, если API не примет шаг, сделанный плагином: вызов главы
  дописывается в конец шага модели, который и так вызывает инструменты.
- Главы не ставятся для пустых сообщений, слэш-команд, сообщений не от пользователя
  (уведомления фоновых задач, другие агенты, сессии и плагины) и сообщений, отправленных
  посреди идущего ответа; в терминальном Claude Code (нет инструмента глав) плагин
  ничего не делает.
- Лог `%LOCALAPPDATA%\MessageChapters\message-chapters.log` (последние 2000 строк,
  общий для всех сессий).
- `deploy.ps1`: проверки и тесты движком Claude Desktop, установка в
  `D:\apps\MessageChapters`, подключение ко всем сессиям через
  `env.CLAUDE_CODE_PLUGIN_DIRS` в `~/.claude/settings.json`, релиз с `-Release`.
